# 截图 → 元件清单（vision 规则）

目标：把一张电路截图变成 `ir_schema.json` 的结构。**先出清单和连接表让用户确认，再落地。**

## 1. 逐元件读三样东西

| 要读 | 从哪读 | 读不到时 |
|---|---|---|
| 类型 | 符号形状 | 写 `type: "?"`，整条 `confirmed: false` |
| 位号 | 元件旁的 R1/C2/Q3 标注 | 按类型自动编号，`note` 写「位号自动生成」 |
| 值 | 标注里的数值与单位 | 写 `"?"`，`confirmed: false` |

## 2. 符号判定（IEC 与中国教材常见画法）

| 图形特征 | 类型 |
|---|---|
| 空心/实心矩形或锯齿折线，两端引线 | R |
| 两条平行短线，不接触 | C |
| 一条直线、一条弧线（或带 + 号） | 电解电容，仍记 `C`，`note` 记极性 |
| 连续半圆线圈 | L |
| 三角 + 顶点竖线 | D（竖线为阴极） |
| 三角 + 竖线带小折角 | 肖特基；带斜线两端 | 稳压（Zener） |
| 圆 + 内部三脚、箭头朝外 | Q（NPN）；箭头朝内 | PNP |
| 栅极与沟道分离的三横线 | M（MOSFET） |
| 三角 + 数字（如 1、2、3） | 运算放大器；引脚极性按 +/− 读 |
| 三条水平线递短 | 接地（net `0`） |
| 竖线 + 顶部横线 + 标注 VCC/5V/V1 | 电源（记 `V`，value = 电压） |
| 圆圈 + 顶部斜箭头 | 电流源 `I` |

不确定就标 `?`。**不猜元件类型**：猜错一个三极管会毁掉整张图。

## 3. 值的读法

- `10k` / `10K` / `10kΩ` → `10k`；`4R7` → `4.7`；`1M` 是兆欧（不是毫欧），`1m` 是毫
- 电容 `104` → `100n`；`4u7` → `4.7u`；`μ`/`u` 统一成 `u`；`nF`→`n`，`pF`→`p`
- 电感单位 `H`/`mH`/`uH` 原样保留
- 二极管写型号（`1N4148`、`1N4007`）；只画符号没型号时 value 留 `?`，note 写「型号待定」
- 运放同理：型号在图上就写 `LM358`，否则 `?`
- 图上出现仿真要求（`V(out)`、`tran 5m`）时，写进 `analysis`，不要自己编参数

## 4. 拓扑（引脚 → 网络）

1. 每段导线是一个电气节点；**两条线交叉处有实心圆点才算连通**，没有圆点是不相连的跨越。
2. 接地符号全部并入网络 `0`。
3. 同一电源符号（VCC 等）的全部实例并入同名网络，名字用标注原文（`VCC`、`+5V`）。
4. 连接关系不明（线被元件标注遮住、截图裁断）→ 该引脚的网络写 `"?"`，整条 `confirmed: false`。
5. 网络命名：优先用图上标签（`Vout`、`mid`），没有就 `n1`、`n2`…；地永远 `0`。

## 5. 输出：确认表（必须贴给用户）

```
| 位号 | 类型 | 值 | 引脚→网络 | 依据 | 确认 |
|------|------|----|-----------|------|------|
| V1 | V | DC 10 | 1→in 2→0 | 左侧电源符号标注 10V | ✓ |
| R1 | R | 1k | 1→in 2→mid | 矩形符号，标 1k | ✓ |
| R2 | R | ? | 1→mid 2→0 | 标注被遮住 | 待确认 |
```

`确认` 列有任何一个「待确认」，就不要往下渲染 netlist —— 先问用户那一项。

## 6. 验收

对 3 张真实截图（分压、RC 低通、共射放大）：

- 元件召回率 100%（漏一个元件这条就不过）
- 参数正确率 ≥95%（读错的必须已在 `?` 里标出来，不算错）
- 网络数、连接关系与人工核对一致

达不到就回去补充规则，别放宽标准。
